# geo-gacha — 唯一無二の幾何学アートをひく

1 日 1 回、9 マスの幾何学模様をひいて集める試作アプリ。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/geo-gacha/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

- 1 日 1 回「ひく」を押すと、9 マスの幾何学模様が 1 枚できる。マスごとに背景色とパーツ（正方形・円・二重円・三角など）がランダムに決まり、
  組み合わせの数はとても多いので同じ絵にはまず出会わない。
- 絵はシード（`No. XXXX-XXXX-XXXX-XXXX`）だけから決まる決定的な生成。今日引いた絵は上に大きく出て、それまでに引いた絵はギャラリーに並ぶ。
  ギャラリーの絵をタップすると額縁つきで大きく見られる。
- 今日すでに引いていたら「また明日」と、次に引けるまでの目安が出る。
- `?debug` を付けて開くと、確認用に何度でも引ける。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
